# Prompt for a new video

Open your coding agent inside the new project folder (so it reads `AGENTS.md`), fill in the <…> parts,
and paste:

```
Create a 3Blue1Brown-style explainer video about <TOPIC, or paper URL / PDF in paper/>.

This project was made from my explainer template; follow AGENTS.md, including its workflow and
the ★ checkpoints where you stop for my feedback.

Audience: <e.g. people who've seen 3b1b's neural-network videos; comfortable with matrices>.
Target length: <e.g. 10–15 min>.
The one idea viewers should leave with: <optional; otherwise propose one in the storyboard>.

Voice: <the default publish-safe TTS (Piper norman) | my own recording, which I'll put in
audio/final/>. Calm pacing with clear pauses between sentences.
Publishing: YouTube, monetized <yes/no>.

Work autonomously between checkpoints and commit after each section.
```

For a concept rather than a paper (e.g. backprop, attention, diffusion), replace "paper URL" with
the topic and say which sources you trust; the honesty rules then apply to those sources.
